# bomb_game_1019
## 🎮 遊戲規則

### 遊戲目標
在 20 × 20 格的地圖中，清除所有可破壞的樹木即可獲勝。小心避開炸彈爆炸範圍，並善用地形保護自己！

### 操作方式
- **方向鍵** 或 **W / A / S / D**：移動角色
- **空白鍵**：放置炸彈
- **重新開局**：開始一場新遊戲，產生新的隨機地圖

### 遊戲規則
- 每場遊戲的地圖會隨機產生樹木與路障。
- **樹木**可以被炸彈摧毀；**路障**無法摧毀，也會阻擋爆炸。
- 炸彈放置後會在 **3 秒後引爆**，初始爆炸範圍為上下左右各 **1 格**。
- 爆炸會沿十字方向延伸，遇到路障時停止；遇到樹木時會摧毀樹木，並停止向該方向延伸。
- 爆炸也會傷害玩家，因此放置炸彈後要及時移動到安全位置。
- 炸彈的爆炸範圍若碰到其他炸彈，會引發連鎖爆炸。

### 生命與道具
- 玩家初始有 **3 條生命**。被炸到會失去 1 條生命；生命歸零時遊戲結束。
- 玩家受傷後會短暫無敵，並移動到附近安全的位置。
- 摧毀樹木時有機會掉落道具：
  - **疾速靴**：提升移動速度。
  - **火焰強化**：增加炸彈爆炸範圍。
  - **炸彈背包**：增加可同時放置的炸彈數量。
- 能力有上限：爆炸範圍最多 **8 格**，炸彈容量最多 **6 顆**。

### 勝利與失敗
- **勝利**：地圖上的樹木全部清除。
- **失敗**：玩家失去所有生命。
- 遊戲結束後，按下「重新開局」即可再次挑戰。
